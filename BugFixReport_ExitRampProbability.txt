Bug Fix Report: Exit Ramp Probability Calculation

Hello Dr. Casey,

I identified and resolved two critical bugs in the exit ramp probability calculation:

================================================================================
Bug 1: Incorrect Denominator in Exit Fraction
================================================================================

Issue:
The exit fraction calculation was using only the first lane flow instead of total mainline flow:

    Incorrect: exitFraction = total_offramp_flow / mainline_lane0_flow
    Result: 65 / 203 ≈ 32-35% exit probability

This caused ~32-35% of all 1,000 vehicles to use the offramp during each 15-minute interval, significantly overestimating offramp usage.

Fix:
Changed denominator to use total mainline flow across all 5 lanes:

    Correct: exitFraction = total_offramp_flow / total_mainline_flow
    Result: 65 / 1000 ≈ 6.5% exit probability

================================================================================
Bug 2: Static Row Index (Stuck at Row 0)
================================================================================

Issue:
The row index remained fixed at 0 throughout the simulation, causing the same exit probability (~35%) to be applied across all 15-minute intervals regardless of time-varying traffic conditions.

Fix:
Implemented proper row advancement mechanism to feed the current row into the simulation. Exit probabilities now update dynamically every 15 minutes using a 5-row moving average smoothing window.
